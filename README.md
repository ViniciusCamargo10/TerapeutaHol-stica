# Patricia Camargo · Terapeuta Holística

Site estático (HTML, CSS e JavaScript puros) da terapeuta Patricia Camargo, com as terapias Multidimensional pelo Coração, Barras de Access e Radiestesia Integrada.

- `index.html`: a página completa
- `img/`: fotos usadas no site

Publicado pelo GitHub Pages a partir da branch `main`.

## Publicar no Firebase Hosting

```bash
npm install -g firebase-tools
firebase login
firebase deploy --only hosting
```

O projeto padrão está em `.firebaserc` (`patricia-camargo`). Se o ID do projeto no Firebase for outro, use `firebase deploy --only hosting --project SEU-ID`.
